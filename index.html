Try the triage scorer

Paste a real subject line and sender, and this runs a transparent, rule-based priority score entirely in your browser — no data leaves this page. This is honestly a rules engine, not a trained model; it demonstrates the triage *logic* the full product would run.

    What's real here, what isn't yet

    The triage scorer above is real, working, rule-based logic — not a fake demo. Separately, this venture also has a code-complete sovereign outbound email gateway (worker.js, dispatches via Cloudflare's native send_email binding — zero Resend/Postmark dependency), but its live deployment status has not been independently re-verified in this pass, so it is not claimed as "live" here.

    Known gap, stated plainly: this venture's own spec describes an inbox client in the Superhuman/Spark/Hey category (reading, filtering, and auto-responding to an existing inbox). What is actually built so far is an outbound sending gateway plus this triage-logic demo — real progress, but not yet the inbox-client product named in the spec.
